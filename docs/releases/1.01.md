# OneZip 1.01

Thanks to vibe coding, an old application gets a second life.

This release rebuilds OneZip with Java 21, a JavaFX Fluent desktop interface, and independently implemented Java archive codecs.

## What's included

- Create and extract ZIP, 7z, TAR, GZIP, LZ4 frame, XZ, BZIP2, and TAR combinations; read supported RAR4/RAR5 archives.
- ZIP32 add/replace/delete, archive descriptions, AES-256 creation, and modification-time preservation.
- One GUI/CLI entry point, bounded parallel workers, progress percentage, throughput, elapsed time, cancellation, and Explorer output selection.
- English, Simplified Chinese, Traditional Chinese, and Japanese; theme colors, light/dark mode, optional image backgrounds, configurable image blur and control transparency.
- A modular bundled Java runtime, centralized version metadata, documented settings, and build scripts.
- English README by default, with Chinese and Japanese editions and privacy-reviewed screenshots made from synthetic sample files.

## Downloads

- `OneZip-1.01-windows-x64.zip`: portable 64-bit application, Java included.
- `OneZip-1.01-windows-x64-setup.exe` / `.msi`: unsigned 64-bit installers.
- `OneZip-1.01-windows-x86.zip`: portable 32-bit application, Java included.
- `onezip-1.01-all.jar`: standalone JAR build for Java 21 on Windows.
- `SHA256SUMS.txt`: SHA-256 checksums for the uploaded binaries.

Unpack the entire portable ZIP and run `OneZip.exe`. For a terminal use `OneZipCLI.exe --help`. `OneZip.exe --cli` selects the same command-line parser.

## Validation and limits

212 non-GUI tests passed, along with compilation, Javadoc checks, and the production codec-dependency audit. Both packaged architectures passed create/list/test/extract content-hash checks for 11 formats and AES ZIP. The final x64 modular GUI passed ZIP/7z creation and extraction, localized table checks, language saving, and a fresh-process restart.

RAR creation and split archives are not supported. ZIP64 and 7z encryption are read-only. Image blur is an application effect; native Windows Acrylic is not included. Installers were generated and statically inspected, but installation/upgrade/uninstallation and Windows 10 hardware have not been fully tested. The x86 portable was tested on 64-bit Windows; no x86 installer is published.
