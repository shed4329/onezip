# JavaFX 主視窗

主視窗採 MVC 分工，使用 JavaFX 21 的 FXML 與 CSS，保留 JMetro Fluent 控制項樣式。

視覺方向採 Windows 10 Fluent：方角控制項、原有檔案圖示、灰色命令列及平面檔案區域。亮暗樣式皆由 CSS 定義，不呼叫原生毛玻璃 API；這是 JavaFX 的視覺實作，不代表增加 Windows 10／舊版系統的執行環境相容保證。

- `MainApplication`：Application 生命週期、FXML 載入、視窗與主題設定。
- `main-window.fxml`：導覽列、工具列、檔案清單和 ZIP 預覽的版面。
- `main-window.css`：亮／暗色彩、間距、導覽選中和焦點樣式。
- `MainWindowModel`：待壓縮來源、目前壓縮檔、目前頁面的可觀察狀態。沒有控制項與對話框。
- `MainWindowController`：FXML 事件、選檔與拖放、狀態綁定，以及呼叫既有 `ArchiveDialogs`。
- `ArchiveDirectory`：從 ZIP entry 建立虛擬資料夾索引，補出缺少的父資料夾並合併明確目錄記錄。保留重名檔案，不解析成本機檔案系統路徑。
- `ZipEntryPreview`：沿用類名以保持資源與測試相容，現為通用歸檔瀏覽器；含可多選的詳細清單、原有圖示、壓縮包注釋、麵包屑及返回／前進歷史，不顯示目錄樹。讀取和建索引在背景執行，導覽使用記憶體索引。
- `ArchiveTask` / `ArchiveEngine`：application 層的背景工作適配與 engine 層的純 Java 實作。

主視窗不再以平行的檔案清單和名稱清單維護同一份資料；TableView 透過 SortedList 觀察 Model 的來源路徑。頁面 visible/managed、來源數量、檔名路徑和動作可用狀態使用 property binding。主視窗沒有側欄，壓縮內容隨視窗寬度填滿可用空間；壓縮頁不另設首頁和設定按鈕，小視窗可垂直捲動參數區。

`SettingsWindow` 直接提供通用、個性化、語言、關於四個分頁；只保留實際接入的控制項，沒有空白搜尋框或無作用的偏好按鈕。壓縮／解壓選項 `ArchiveDialogs` 和 ZIP 預覽元件也以 Java 建立。設定的儲存位置與錯誤修正不需要重做視窗。

設定統一存放於 `%LOCALAPPDATA%\OneZip\settings.properties`，使用 UTF-8 key/value 格式，先寫同目錄暫存檔再替換。首次讀取會在新設定不存在時，匯入 `%TEMP%\OneZip\FX_GUISetting.txt` 和 `NormalSetting.txt`，保留舊檔；新設定優先，不會重複覆蓋。格式損壞或讀取失敗時使用預設值，在設定頁顯示提示並拒絕覆寫既有損壞檔案；保存失敗不更新記憶體中的設定。缺失或損壞的光標圖片會退回系統預設光標。

測試可用 `-Donezip.settings.dir=...` 與 `-Donezip.settings.legacy-dir=...` 指定隔離目錄。`scripts/PackagedGuiSmoke.java` 以發行 JAR 作為唯一 classpath 載入主視窗、檔案圖示和原有設定頁，避免僅測試開發目錄而漏掉 JAR 資源路徑問題。執行方式：`java -Donezip.settings.dir=target/packaged-settings -Donezip.settings.legacy-dir=target/empty-legacy -cp target/onezip-1.01-all.jar scripts/PackagedGuiSmoke.java target/packaged-input`。

ZIP 瀏覽支援雙擊／Enter 進入資料夾，Backspace 返回上一層，Alt+左／右返回與前進，以及點擊路徑節點。重新讀取或切換壓縮包會返回根目錄並清空歷史。統計是目前資料夾的直接子項數；提示顯示壓縮包原始記錄數。瀏覽不解壓內容，主工具列「全部解壓」仍解出整個壓縮包。

開發時修改 FXML/CSS 後需重新 `mvnw.cmd package`；啟動腳本在 JAR 已存在時不會自動重新打包。GUI 回歸使用 `mvnw.cmd -Dtest=GuiSmokeTest test`，包含實際 FXML 載入、壓縮／解壓、ZIP 預覽、頁面切換、視窗縮放和亮暗截圖。

解壓頁使用完整視窗寬度與黑灰色背景，壓縮頁和解壓頁均不顯示左側欄。工具列為「打開、解壓、新建、添加、刪除｜注釋、編碼方式」，採用既有 PNG 圖示；設定以按鈕直接放在工具列最右側；測試、密碼和重新讀取放在檔案列表右鍵選單，不再顯示更多按鈕。移除獨立檔名／路徑提示列，工具列與按鈕不使用圓角，工具列貼邊且無外邊距。移除目錄樹及其切換選項。檔案列表與下方唯讀注釋區可用分隔線調整高度，注釋文本框無邊框和內外間距並填滿面板，沒有文件內容預覽、十六進制或屬性頁。移除搜尋功能與選取複選框，改用檔案管理器的單擊、Ctrl 多選、Shift 連選、Ctrl+A 全選邏輯；多選用於刪除與統計，底部僅顯示統計；「解壓」仍解出整包，選取範圍不影響解壓。

`ZipEditor` 提供 ZIP32 添加／替換和刪除；讀取原目錄與現有條目範圍，複製保留的 local records，使用既有 `ZipWriter` 壓縮新項目，重建 central directory 並修正位移。原有條目的密碼、壓縮位元流與元資料不改動，新增檔案不加密。修改前先確認，失敗或取消會清理暫存包並保留原包；替換前檢查原包是否被其他程序更改。ZIP64 與非 ZIP 格式暫不提供編輯。 相鄰 local records 合併成區段，以 FileChannel.transferTo 每次最多 8 MiB 複製；無進度時退回有界緩衝複製。非實體順序的目錄仍按原目錄順序修正位移，刪除造成的間隙不會誤複製為保留項目。純刪除不建立新增 ZIP 或壓縮工作區；沒有變更直接返回，不重寫原檔。新增來源共用傳輸緩衝。

檔名編碼可選自動（UTF-8／CP437）、UTF-8、GB18030、Big5、Windows-1252。自訂編碼只改變未標記 UTF-8 的原始 ZIP 名稱解碼，UTF-8 標記與有效 Unicode path extra 保持優先。瀏覽與解壓使用相同編碼，避免顯示正常而輸出亂碼。

`ArchiveEngine.listArchive` 同時取得目錄與壓縮包注釋，`listDetails` 提供可選元資料，保留原有 `list` API。ZIP 額外讀取壓縮大小、DOS 修改時間（無時區）、方法、加密、CRC 和注釋；AE-2 不提供 CRC 時顯示「—」。ZIP 注釋只在詳細瀏覽時讀取，正常解壓不額外讀注釋。其他 reader 未公開的元資料不推測。瀏覽不等於完整測試；串流格式使用既有私有暫存索引，可能需要完整解碼並使用暫存磁碟。

启动页由 `MainWindowModel.Page.HOME` 控制。首页使用 FXML 的 2×2 四入口布局（压缩、解压、设置、关于），没有额外搜索、最近列表或功能占位。设置和关于复用原设置窗口与原关于页面，不改其布局。返回首页会保留当前来源和已打开归档状态；再次选择归档时会重新读取目录。首页压缩包拖放直接进入解压列表，其他文件拖放进入压缩来源页。

建立壓縮檔的來源頁透過統一「添加内容」選單或拖放加入檔案與資料夾，上方詳細列表顯示名稱、大小、類型、修改日期與完整路徑，支援 Ctrl 多選、移除、清空、欄位排序和選取項目上移／下移。下方左側為常駐壓縮設定，右側為可折疊高級選項，開始壓縮位於右下角。常用 ZIP／7z／TAR／TAR.GZ 格式可直接切換，其餘輸出格式使用同列下拉選單。檔案屬性由有界背景工作讀取；資料夾大小不遞迴掃描，總大小標明已知下限。常駐「壓縮設定」提供格式、檔名、保存位置及 ZIP 密碼；副檔名隨格式更新，支援瀏覽選擇保存資料夾，「開始壓縮」直接使用這些設定。高級選項放壓縮等級與執行緒數（0 為自動），折疊後仍能使用基本設定。檔名與位置在開始前驗證，已有輸出不覆蓋。首頁拖入一般檔案同樣能進入壓縮來源頁。

ThemeManager 統一管理即時亮暗切換，設定保存成功後更新所有已註冊視窗；設定視窗保持原有版面，解壓頁的設定入口會恢復最小化視窗並帶到前景。

進度視窗每 250 ms 更新完成百分比，視窗標題同步顯示百分比；速度以引擎報告的原始處理位元組數按約 0.75 秒採樣計算，自動使用十進位 MB/s 或 kB/s，完成後顯示平均速度。壓縮速度包含已送入緩衝區的輸入，不等於磁碟寫出速度；掃描期間尚無總量時不虛構百分比。取消時解除進度綁定、凍結並改為紅色，停止速度採樣，保留原有暫存清理；修正同步取消事件被按鈕邏輯覆蓋而卡在「正在取消」的問題。

進度彈窗採任務標題、歸檔名稱、進度條與右側百分比、當前檔案、速度及剩餘時間、底部動作的版面。剩餘時間以近期原始資料處理速度估算，掃描或速度不足時顯示正在估算；輸入送完但尚未成功提交輸出時顯示正在完成。完成後開啟目標資料夾為預設關閉的可切換選項，只在成功後定位並選中目標（壓縮選中產生的壓縮包，解壓選中輸出目錄）；測試任務不提供此選項。取消／失敗會停用此選項。

進度資訊增加固定到結束時的已用時間（HH:mm:ss）、當前檔案在任務清單中的序號／檔案總數，以及已處理／總量 MB（十進位原始資料大小）。目錄不算檔案；多 worker 顯示最近回報檔案的清單序號，並非已完成檔案數。Progress.files 為具預設空實作的計畫通知，既有 lambda 回呼保持相容。完成進度條為綠色，取消／失敗為紅色。

Windows 的定位選中使用獨立 UI FileManager，以系統 Explorer 的 /select 與獨立路徑參數執行，不經 cmd 或 PowerShell；含空格與 Unicode 的路徑不拼接成 shell 命令。此程序僅供檔案管理器定位，所有壓縮／解壓演算法仍維持純 Java、無外部程序委派。非 Windows 僅在 JDK Desktop 支援定位時執行，否則回報不支援，不默默改為開啟檔案。

建立 ZIP 時可在高級選項的「文件说明」輸入多行全域注釋，UTF-8 上限 65535 bytes；非 ZIP 格式停用此欄位。注釋直接寫入完成編碼後的私有暫存 ZIP，再檢查取消並發布輸出；失敗仍清理暫存檔，不在成功發布後補寫。支援中文、換行及帶密碼的 ZIP。既有歸檔可繼續透過解壓工具列的注釋功能編輯。

文件说明输入区为八行偏好高度、最小 160px，避免高级选项布局压缩成单行。已有 ZIP 的文件说明编辑同样采用多行 TextArea，保存时保留换行并验证 UTF-8 长度。创建前拒绝 Windows 保留文件名；来源计划进度回调若抛异常，也会清理私有暂存包。任务进度仅在引擎成功返回后达到 100%，不再以文件名称「完成」判断结束。

本地背景：設定原有個性化→設定背景頁新增應用背景圖片與圖片模糊，保留光標與夜間模式。背景圖只從本機載入，以 cover 裁切並限制解碼尺寸；文字、清單和按鈕不參與 GaussianBlur。圖片路徑和模糊開關以同一次設定寫入保存；讀取缺失圖片時回退主題，選擇無效新圖片不覆寫有效設定。移除原本個性化頁的整窗 opacity=0.85；整窗透明不代表毛玻璃。

視覺採中性色面板、少量 5px 面板圓角及間距，不從背景吸取配色。來源工具列統一「添加内容」下拉選單提供檔案／資料夾，保留 Ctrl 多選、無側欄／檔案樹，高級選項預設折疊。

外觀實測使用 `scripts/AppearanceProbe.java` 和發行 JAR，設定隔離在 target/appearance-probe/settings，來源圖 test-background.jpg；真實桌面截圖、API 回傳值及 PASS/FAIL/NOT_TESTED 項目在 target/appearance-probe。`AppearanceRestoreProbe.java` 額外驗證全新 JVM 恢復背景設定。生成的 ui-reference-generated.png 僅是設計參考，不是測試證據。

系統材質實驗腳本 `scripts/ProbeWindowsBackdrop.ps1` 只定位指定標題且 PID 符合的測試窗口，以 DwmEnableBlurBehindWindow 和 DwmSetWindowAttribute 測試；不編入生產引擎，也不自動套用到其他窗口。API 成功與視覺通過分開判斷：變換 OneZip 背後的獨立高頻色塊，檢查客戶區的反應和高頻衰減。build 26300 的本輪 API 設定／讀回成功，兩種系統模糊均未通過客戶區視覺驗證，故未作為可用功能啟用。Windows 10 實機及原生選檔視窗手動操作標為未測。

官方限制：[DWM_SYSTEMBACKDROP_TYPE](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type) 最低為 Windows 11 build 22621；[DwmEnableBlurBehindWindow](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmenableblurbehindwindow) 說明 Windows 8 起不再產生原有模糊效果。Win10 Fluent 的視覺設計不代表 Windows 10 原生材質已通過測試。
